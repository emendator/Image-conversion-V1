# 高级动效与表现设计说明（Motion Premium Layer）

> 本次升级在原有「细节工艺」动效体系（`ui-details.css` / `login.css`）之上，
> 新增了一套**零依赖、手写实现**的高级动效层，覆盖「华丽高级」动效参考中的主要类别，
> 同时严格遵循原有设计原则：**克制、低对比、transform/opacity 驱动、尊重 `prefers-reduced-motion`**。

---

## 一、新增文件

| 文件 | 职责 |
| --- | --- |
| `frontend/src/motion-premium.css` | 全部高级动效样式（极光/流光/骨架屏/3D 倾斜/磁性/涟漪/滚动揭示/玻璃顶栏/光标光晕/弹簧控件） |

## 二、实现的动效类别（对照设计参考）

### 🌊 流体与液态类
- **极光背景（Aurora）**：`ui-aurora` 双层大尺度径向渐变缓慢漂移旋转（transform 驱动，GPU 友好），首页启用。
- **悬浮光球（Orb）**：`ui-orb` 低频呼吸漂浮，首页 4 个 / 图片库 2 个，低透明度点缀。
- **动态渐变文本**：`ui-text-flow` 标题渐变持续流动，并与逐字入场动画**组合**（`.ui-char.ui-text-flow`），入场错峰、渐变相位随字错开形成波浪感（首页 + 登录页标题）。
- **流光扫过（Shimmer）**：`ui-shimmer` 徽章持续流光（首页「已就绪」）；`ui-btn-shimmer` 按钮悬停流光（所有主操作按钮）。

### ✨ 入场与过渡类
- **滚动揭示（Scroll Reveal）**：`ui-scroll-reveal` 上移 + 模糊消散入场，三个生成器页的左栏面板按 0.06s 步进错峰；揭示完成后自动 `is-settled` 解除过渡，**不影响后续按钮悬停等微交互**。
- **网格逐项点亮（Grid Reveal）**：`ui-grid-item` 图片库网格 **3D 翻转揭示**（俯视翻起 → 落平，容器 perspective 900，每项 0.05s 步进），揭示后让位给 3D 倾斜。
- **弧形入场（ArcIn）**：`ui-arc-in` 首页功能卡沿弧线轨迹飞入（横向偏移 + 微旋转 + 缓出）。
- **弹性入场（BounceIn）**：`ui-bounce-in` 首页 Logo 弹簧回弹入场；Toast 改为弹性弹入（先过冲后回落）。
- **3D 翻转入场（FlipIn）**：`ui-flip-in` 电商页右栏「拖拽排版 ↔ 生成结果」Tab 切换时内容 3D 翻起落平（key 重挂载触发）。
- **FLIP 布局动画**：`flipLayout()` 工具（motion.ts 导出），图片库切换网格图标尺寸（大/中/小）时卡片位置平滑过渡（仅合成层 transform，无回流）。
- **手风琴平滑展开（Smooth Accordion）**：`ui-acc` / `ui-acc-inner` 基于 `grid-template-rows: 0fr→1fr`，高度 auto 平滑展开 + 收起时 `visibility` 延迟隐藏（不可聚焦）；已应用于电商/切片页「模板」「文字叠加」面板（含切片子面板）、海报页底图选择区、API 设置高级选项。
- **乱码解码（Glitch Text）**：`<DecodeText />` 组件，三个生成器画布加载遮罩的状态文字从随机字符逐渐「解码」为清晰内容，贴合 AI 生成语义。
- **动态复选框**：主题色 `accent-color` + 勾选弹跳（`uiCheckPop`）+ 按压缩放。
- **弹簧缓动**：`--spring: cubic-bezier(0.34, 1.56, 0.64, 1)` 用于开关/滑块/箭头/Toast/入场等微交互，物理回弹更自然。

### 🖱️ 微交互与光标类
- **3D 悬浮卡片（Tilt + Glare）**：`ui-tilt` 跟随鼠标 3D 旋转（指数平滑插值），`ui-tilt-glare` 高光径向跟随鼠标位置。首页功能卡（8°）+ 图片库网格卡（6°，`data-tilt-max` 可调）。
- **磁性悬停（Magnetic）**：`ui-magnetic` 卡片向光标轻微吸附（22% 比例、半卡范围内封顶），与 3D 倾斜共用同一 rAF 插值循环。
- **点击涟漪（Ripple）**：`ui-ripple` 捕获阶段监听（不受 React stopPropagation 影响），所有主按钮 + 首页卡片。
- **光标氛围光晕（Cursor Glow）**：自动创建的柔和光晕跟随光标（lerp 0.12），仅 `(pointer: fine)` 且非减少动效时启用，z-index 850 不遮挡弹窗/顶栏。
- **果冻回弹（Jelly）**：`ui-jelly` 首页 Logo、卡片图标悬停回弹（squash & stretch）。
- **骨架屏波浪（Skeleton Wave）**：`ui-skeleton` 图片库加载网格、三个生成器画布加载遮罩。
- **数字滚动（Count-up）**：`<CountUp />` 顶栏 Token、首页累计消耗、API 设置弹窗三项统计、生成结果 Token 消耗徽章。
- **悬浮浮动**：`ui-float` API 状态图标、空态图标轻微漂浮。
- **弹簧开关**：`ui-switch-track/knob` 电商页 AI 开关（knob 弹簧位移 + 按压放大）；`ui-seg-thumb` 海报页两处分段滑块改为 **transform 弹簧滑动**（避免 left 布局抖动）。

### 🧩 布局与容器类
- **毛玻璃吸顶导航（Glass Sticky Header）**：`ui-header` backdrop-filter 毛玻璃，滚动后加深 + 投影（`.scrolled`）。
- **阅读进度指示器**：全局顶部 3px 渐变进度条（scaleX，无回流），非滚动页自动隐藏。
- **高级加载指示器**：`ui-spinner` 主题色双环 + 光晕，替换旧式单环。
- **精致滚动条 + 焦点环**：主题色渐变滚动条；`:focus-visible` 主题色描边（排除表单控件避免双重焦点环）。

## 三、性能与可访问性

- 全部动画使用 `transform` / `opacity` / `background-position`（无布局抖动），`will-change` 仅用于必要元素。
- 全局 `prefers-reduced-motion: reduce`：所有持续动画停止、揭示元素直接显示、光标光晕/吸顶模糊关闭、过渡禁用。
- `@media (pointer: coarse)`：隐藏光标光晕（触屏无意义）。
- 滚动揭示的隐藏态由 `js-motion` 根类门控：无 JS 时内容始终可见，不会出现空白。
- 动效引擎全部为**事件委托 + 观察者**：新增 DOM（SPA 路由切换）由 MutationObserver 自动接管，无需在每个组件里手动初始化。

## 四、刻意未采用的效果（避免「炫技」损害工具感）

- 3D 环形排列、书本翻页、时间线帧动画、滚动故事叙事：
  本项目是生产工具而非营销页，此类叙事性/装饰性动效会干扰高频操作与信息密度。
- 自定义光标形状/粒子光标：影响操作精准度，仅采用柔和氛围光晕。
- 乱码解码仅用于「生成中」加载遮罩的状态文字（贴合 AI 语义），未用于标题/正文等静态内容。

## 五、登录页背景「液态光效」升级（login.css / Login.tsx）

在原有「交互式流体扭曲 + 悬浮粒子」基础上叠加了一套**多层级液态光效背景**，
从深到近共 9 层（全部 `z-index: 0`、`pointer-events: none`，内容区 z-1 之上）：

| 层级 | 效果 | 说明 |
| --- | --- | --- |
| 1 极光层 | `login-aurora` 三块大尺度色斑 | blur(70px) 缓慢漂移旋转（24/30/36s 错峰），**深层视差 -26px** |
| 2 丁达尔光柱 | `login-ray` 三道柔和光束 | 上宽下窄渐变，缓慢摆动（13~17s 错峰），近层视差 10px |
| 3 流体层 | 原有跟随光晕 + 单向流动 | 增加玫红/品红色斑，与蓝紫形成虹彩过渡 |
| 4 悬浮粒子 | 原有发光小光球 | 保留 |
| 5 玻璃光球 | `login-glass` 六片毛玻璃圆角片 | backdrop-filter 模糊**覆盖在流动流体之上**，形成「液态玻璃」质感；外层浮动旋转（18~24s 错峰），**中层视差 16px** |
| 6 流星 | `login-star` 光迹 | 偶发划过夜空（8~11s 周期、错峰延迟），尾迹渐变 |
| 7 胶片颗粒 | `login-grain` SVG feTurbulence 噪点 | opacity 0.05 + steps(4) 低速抖动，电影质感 |
| 8 暗角 | `login-vignette` 径向压暗 | 边缘 0.16 柔化收束，聚焦中心 |
| 9 点击涟漪 | `login-ripple-ring` | 点击空白处泛起主题色光环（交互区自动忽略） |

交互细节：
- **多层级鼠标视差**：极光 -26px / 玻璃 16px / 光柱 10px，rAF 指数平滑惰性跟随，营造空间纵深；
  与原有「跟随光晕」的快速跟手形成快慢对比。
- 点击涟漪通过 `closest('button, input, select, textarea, a, .login-pill, .login-card3d, .login-flip')`
  排除所有交互区域，只在纯背景上触发。
- `prefers-reduced-motion`：极光/玻璃/光柱/流星/颗粒全部隐藏，点击涟漪不生成。

## 六、工艺细节层（detail.design 风格质感精修）

参照 detail.design 的「品味优先」标准，在动效之上打磨工艺细节（多为**静态质感**，低调但耐看）：

- **分层阴影系统（Layered Elevation）**：全部面板/卡片由单层 `0 2px 12px` 升级为「近接触阴影 + 环境大阴影」双层（`0 1px 2px rgba(15,23,42,.04), 0 8px 24px rgba(15,23,42,.07)`），弹窗升级为 `0 2px 8px + 0 24px 80px`，立体感更真实。
- **字体渲染（Typography）**：字体栈补入 PingFang SC / HarmonyOS Sans SC / Noto Sans SC；全局 `-webkit-font-smoothing: antialiased` + `text-rendering: optimizeLegibility`；标题/按钮 `letter-spacing` 微调。
- **按钮按压力度（Press Depth）**：主按钮按下 `translateY(1px) scale(0.99)`，物理按压感。
- **Toast 工艺升级**：图标放入半透明圆形徽章 + **自动消失进度条**（3s scaleX 收缩，让「即将消失」可预期）。
- **结果弹出揭示（Pop-in）**：`ui-pop-in` 生成结果出现时温和放大浮现（电商页，key 重挂载触发）。
- **图片悬停微缩放**：图库网格图片 hover 时 1.06 倍缓慢放大（`var(--ease-out)`）。
- **空状态温度（Empty State）**：图片库/模板空态改为渐变图标徽章（`ui-empty-icon`）+ 有温度的文案（「图片库还是空的」「把第一个模板带回家」）。
- **首页卡片氛围光**：hover 阴影由纯黑改为主题色光晕（`rgba(var(--accent-rgb), .18)`）。

## 八、扩展指引- **给任意元素加 3D 倾斜**：加 `ui-tilt` + 子元素 `ui-tilt-glare`，可调 `data-tilt-max`。
- **加磁性**：加 `ui-magnetic`（可与 tilt 同用）。
- **加涟漪**：加 `ui-ripple`。
- **加滚动揭示**：加 `ui-scroll-reveal` + 内联 `--reveal-delay`（网格用 `ui-grid-item`）。
- **加入场预设**：`ui-arc-in` / `ui-bounce-in` / `ui-flip-in`（动画结束后需移除类名以释放 transform 给后续 JS 动效）。
- **加手风琴**：内容外包 `<div className={'ui-acc' + (open ? ' ui-acc-open' : '')}><div className="ui-acc-inner">…</div></div>`。
- **加 FLIP**：布局变化时 `flipLayout(containerRef.current)`（元素需带 `data-flip`）。
- **加乱码解码**：`<DecodeText text="…" />`。
- **加流光**：徽章 `ui-shimmer`，按钮 `ui-btn-shimmer`。
- **加骨架屏**：`<div className="ui-skeleton" style={{ height: 12 }} />`。
- **加数字滚动**：`<CountUp value={n} />`。
- **加弹出揭示**：结果出现时外层加 `className="ui-pop-in"` + `key`（变化触发重放）。
- **加空态徽章**：`<div className="ui-empty-icon">🖼️</div>`。
- **加阴影体系**：面板 `0 1px 2px rgba(15,23,42,.04), 0 8px 24px rgba(15,23,42,.07)`；弹窗 `0 2px 8px rgba(15,23,42,.10), 0 24px 80px rgba(15,23,42,.22)`。
